# Pawan Mishra — Interactive Developer Portfolio

## ✨ Features

- **Interactive Hero** — Dynamic cursor spotlight, animated headline, magnetic CTA buttons
- **Project X-Ray** — Architecture node diagrams for each project on hover
- **Command Palette** — `Ctrl + K` to navigate the portfolio like an IDE
- **Terminal OS** — In-browser terminal drawer with portfolio commands
- **AI Assistant** — Ask AI about Pawan's skills and experience
- **Skill Universe** — Interactive 3D-style skill visualization
- **Custom Cursor** — Context-aware cursor with label changes
- **Loading Screen** — Boot-style animated loader
- **Scroll Progress** — Top bar scroll indicator
- **Fully Responsive** — Mobile-first, works on all screen sizes
- **Dark Editorial Design** — Premium dark theme with micro-animations

## 🏃 Run Locally

```bash
# Clone the repo
git clone https://github.com/mishraji018/Portfolio_mine.git

# Navigate into the project
cd Portfolio_mine

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

---

## 📦 Build for Production

```bash
npm run build
```

## 📁 Project Structure

```
src/
├── components/
│   ├── effects/        # TextReveal, InteractiveTitle
│   ├── navigation/     # Navbar, MobileMenu, CommandPalette
│   ├── projects/       # ProjectPreview, ProjectXRayModal
│   ├── sections/       # All page sections
│   └── ui/             # CustomCursor, LoadingScreen, etc.
├── data/
│   └── projects.ts     # Project data (edit here to update projects)
├── pages/
│   └── Index.tsx       # Main page — section order lives here
└── index.css           # Design tokens & global styles
```
